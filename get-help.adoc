NetApp 以各种方式为 Trident 提供支持。我们提供全天候免费自助服务选项，例如知识库 (KB) 文章和 Discord 频道。



[[trident-support-lifecycle]]
== Trident 支持生命周期

Trident 根据您的版本提供三个级别的支持。请参阅 link:https://mysupport.netapp.com/site/info/version-support["NetApp 软件版本支持的定义"^]。

完全支持:: Trident 从发布日期起提供 12 个月的全面支持。
有限支持:: Trident 在发布日期后的第 13 - 24 个月提供有限支持。
自助支持:: Trident 文档自发布之日起 25 - 36 个月内可用。

[[community-support]]
== 社区支持

我们的 link:https://discord.gg/NetApp["Discord 频道"^] 上有一个充满活力的容器用户（包括 Trident 开发人员）公共社区。这是询问有关该项目的一般性问题并与志同道合的同事讨论相关主题的好地方。



[[netapp-technical-support]]
== NetApp 技术支持

要获得有关 Trident 的帮助，请使用 `tridentctl logs -a -n trident`创建支持包并将其发送到 `NetApp Support <Getting Help>`。
